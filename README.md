# Static Website Template

This is a minimal static website template for GitHub Pages or any simple project.

## issues
if you have any issues or requests go to the [main repo](https://github.com/QuickStart-repos/QuickStart-repos)
and submit it.


## Structure

- `index.html` – main page
- `style.css` – default styles
- `script.js` – default JS file
- `images/` – folder for images

## Usage

1. Use this repo as a template and add tour content
2. Replace content in `index.html`, `style.css`, and `script.js` as you need to.
3. enable pages and youre done.
